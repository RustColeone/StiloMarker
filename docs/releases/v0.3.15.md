Stilo Marker is a Markdown workspace for writing: notes, diagrams, characters and chats, alone or together with others. It runs in the browser, as an installable web app, or as this desktop app, which works on its own and can run a server for others to join.

This release follows v0.3.1, whose draft was taken down to fix the usability problems found in it first.

## Downloads

All portable: nothing to install, nothing left behind but your settings and work.

| System | File |
|---|---|
| Windows (64-bit) | `StiloMarker-0.3.15-win-x64.zip`: unzip, run `StiloMarker-0.3.15-win-x64.exe` |
| macOS, Apple Silicon | `StiloMarker-0.3.15-mac-arm64.zip`: unzip, open Stilo Marker |
| macOS, Intel | `StiloMarker-0.3.15-mac-x64.zip`: unzip, open Stilo Marker |
| Linux (64-bit) | `StiloMarker-0.3.15-linux-x86_64.AppImage`: make it executable (`chmod +x`), run it |

The builds are not signed, so the first start asks once:

- **Windows** may say it protected your PC when you run the `.exe`: choose **More info**, then **Run anyway**.
- **macOS** says it cannot check the app: open **System Settings → Privacy & Security** and choose **Open Anyway** (or right-click the app and choose **Open**).

`SHA256SUMS.txt` lists each file's checksum.

Running a server from the app (Settings → Server, for others to join) needs Python 3.10 or later on the computer. Everything else works without it.

The app tells you when a newer release is out (the status bar's "Update available" opens its page).

## In this release

- **Two source editors.** Each pane has its own editor, so two files, or the same file twice, can be edited side by side (a tab's **Open to the Side**). The same file in both stays in step as you type, each pane shows the other's caret, and Ctrl+Z undoes the file's last change from either pane. The pane you last worked in holds the open file; Find, completions and comments follow it.
- **The left window has tabs.** The activity bar's icons are its tabs: the Explorer, Search (find text in every file, Ctrl+Shift+F), and any panel you drag there. Click the icon of the tab showing to hide the window. The right panel (Agent, Chats) has its own button at the right end of the top bar.
- **Search file names** in the box above the Explorer's tree: it keeps the files and folders whose name matches, Enter opens the first, Escape clears it.
- **Desktop app: one bar.** No separate title bar: the app's top bar is the window's (drag it to move the window), with the window buttons drawn in the theme's colours.
- **Desktop app: zoom** with Ctrl+= / Ctrl+- / Ctrl+0 (Cmd on a Mac) or Ctrl+wheel, or View → Zoom In / Zoom Out / Reset Zoom. The zoom is kept for next time.
- **Smaller fixes**:
  - after a reconnect, the caret stays where it was (it could jump to the start of the file);
  - Open Project opens a project only with its Open button;
  - a pane's Source / Preview switch changes its tab in place;
  - the tab in use is the darker one in every theme;
  - a team project's tree shows the project's name;
  - Settings → Agent says "Checking the server…" until it has.

If something about the new title bar looks wrong on your system (the window buttons' place or colours, a part of the bar that does not drag), please say so: it has been tried on Linux and Windows, not yet on macOS.

The full list of changes and fixes is in `docs/ISSUES.md`.
