Stilo Marker is a Markdown workspace for writing: notes, diagrams, characters and chats, alone or together with others. It runs in the browser, as an installable web app, or as this desktop app, which works on its own and can run a server for others to join.

This is the first desktop release, from the stable line (v0.3.0, gone over again before calling it so, and v0.3.1).

## Downloads

All portable: nothing to install, nothing left behind but your settings and work.

| System | File |
|---|---|
| Windows (64-bit) | `StiloMarker-0.3.1-win-x64.exe`: run it |
| macOS, Apple Silicon | `StiloMarker-0.3.1-mac-arm64.zip`: unzip, open Stilo Marker |
| macOS, Intel | `StiloMarker-0.3.1-mac-x64.zip`: unzip, open Stilo Marker |
| Linux (64-bit) | `StiloMarker-0.3.1-linux-x86_64.AppImage`: make it executable (`chmod +x`), run it |

The builds are not signed, so the first start asks once:

- **Windows** may say it protected your PC: choose **More info**, then **Run anyway**.
- **macOS** says it cannot check the app: open **System Settings → Privacy & Security** and choose **Open Anyway** (or right-click the app and choose **Open**).

`SHA256SUMS.txt` lists each file's checksum.

Running a server from the app (Settings → Server, for others to join) needs Python 3.10 or later on the computer. Everything else works without it.

The app tells you when a newer release is out (the status bar's "Update available" opens its page).

## In this release

- **Find in Files**: search every file of a workspace (match case, whole words in any language, regular expressions), and replace in all of them with one Undo.
- **Text and data files**: `.txt` and `.log` as plain text, `.json` with its errors pointed out, and `.csv` / `.tsv` in a table editor that handles 20,000 rows, sums up the numbers you select, and copies and pastes like a spreadsheet.
- **Spellcheck**, as a setting, with the desktop app's right-click suggestions.
- **Accounts on your own server**: passwords stored hashed, an admin page (Settings → Accounts), and `server/accounts.py` for the command line. In the desktop app, Settings → Server → **Turn On Accounts…** makes the first admin. A browser stays signed in with a token (never a password) through server restarts, until you sign out, the password changes, or 30 days pass unused.
- **Shared sessions**: a warning when the connection keeps dropping; a host coming back to the tab no longer ends the session for guests.
- **Extensions**: a documented extension API (version 1, `docs/EXTENSIONS.md`); tables, diagrams, Mermaid, HTML pages, URL albums and extra themes are extensions.

### Security fixes for anyone hosting a server

Before this release, someone signed in with edit access to a team project could create files outside that project's folder on the server, and anyone in a session could upload over a project's access list. Both are fixed, along with other hardening: sessions end when an account is removed, given a new password or taken out of a team; sign-ins expire; repeated wrong passwords slow down; the account file is never served. If your server's account file predates hashed passwords, convert it once, on the server: `python3 server/accounts.py convert --admin <name>`.

The full list of changes and fixes is in `docs/ISSUES.md`.
