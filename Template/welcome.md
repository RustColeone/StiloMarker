# STILO MARKER

A place to write: notes and chapters in Markdown, diagrams, image albums and tables, each beside its preview. This project is a sample to try things in; change it, delete it, or start your own with **File → New Project**.

## Where your work is kept

Until you sign in, everything stays in this browser and is saved as you type (the status bar says **In-browser workspace**). It is still here when you come back; clearing this site's data in the browser removes it, so keep a copy of what matters with **File → Export Project Zipped**.

- **File → Import Local Folder** or **Import File or Zip** brings files in.
- **File → Save as PDF** prints the open note's preview.

## Writing

- Click a file in the explorer on the left to open it. The **Create** menu makes new ones: Markdown, a diagram, a table, an HTML page and more.
- Each pane is a row of tabs. At first the left one edits and the right one previews. Right-click a tab to show it as Source or Preview, move it to the other pane, or **Open to the Side** to edit it in both at once.
- `Ctrl+Z` undoes the file's last change, made in either pane.
- Link one file to another with `[a name](other-file.md)`, like this link to [the brainstorm diagram](welcome.bmap). Hovering a link in the editor shows its file, `Ctrl+Click` opens it, and **Linked Notes** under the explorer lists the links both ways.
- `Ctrl+Shift+F` searches (and replaces) in every file; the box above the tree finds files by name.

## The files in this sample

- **welcome.md**: this note.
- **welcome.bmap**: a brainstorm diagram. In the preview, drag its boxes; ✎ edits them and their connections.
- The **.mtree** file: a map of how things relate, written as an indented outline and drawn as a tree.
- **Images/LULUKA.urldb**: an album of image links. Click an entry to see it.

## Working with others

On a server with accounts, sign in (**Settings → Collaboration**, under Account) and open a team's project with **File → Open Project…**. Everyone in it sees the others' typing and carets as they go, and your tabs come back on any device.

Without an account, a PIN shares a session, in the same place: **Share** under Share This Workspace lets others join yours, and **Join** with someone's PIN joins theirs.

## The Agent and Chats

The right panel (**View → Show Chat**, or the button at the right end of the top bar) holds the **Agent**, which can read and change your files when you ask, and **Chats**, for talking with the characters you write. They need a sign-in on a server that offers them, or your own API key in **Settings → Agent**.

## More

- `F1` (**View → Run Command…**) lists every command.
- **Settings → Appearance**: themes, the editor's font, a spelling check.
- On a phone, ≡ opens the explorer, and the first button at the top right switches the file between Source and Preview.
- Your browser can install the app (Chrome and Edge from the address bar; on an iPhone, Share → Add to Home Screen); installed, it works offline too.
- If something seems stuck, **Settings → Reload Window** reloads without losing work.
